# NBA Box Score Analysis

This project analyzes which NBA box-score statistic are most strongly associated with point differential and winning.

## Project Overview

This project examines which NBA box-score statistics are most strongly associated with point differential and winning. The analysis focuses on statistics such as shooting efficiency, rebounds, and assists.

## Research Question

Which box-score statistics are most strongly associated with point differential and winning in NBA games?

## Hypothesis

I hypothesize that shooting efficiency will have the strongest relationship with game performance. Other things like rebounds and assists might also have significant relationships.

## Dataset

The dataset contains NBA game results and team statistics for both the home and away teams. It includes points, rebounds, assists, field-goal percentage, three-point percentage, free-throw percentage, and other game statistics.

The CSV file for the project is [games.csv](games.csv)

## Current Analysis

The first part of the project examines whether rebound differential is related to point differential. Correlation, linear regression, a histogram, and a t-test are used to analyze this relationship.
